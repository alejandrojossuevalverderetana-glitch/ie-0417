# IE-0417 — Software Engineering Coursework

This repository contains coursework, laboratory exercises, documentation, and software development activities completed as part of the IE-0417 course at the University of Costa Rica (UCR).

The repository documents practical work throughout the course, covering software development practices, implementation, testing, documentation, and development environments.

## Topics and Activities

- **Software Design and Documentation:** UML diagrams, activity diagrams, database modeling, and software development methodologies.
- **C++ Programming:** Implementation exercises involving source files, code organization, and debugging.
- **Software Testing:** Test cases for components such as authentication and calculator modules.
- **Web Development:** A basic web application developed using Python and Flask.
- **Containerization:** Docker images, multi-stage builds, and Docker Compose configurations to simplify application setup.
- **Development Tools:** Version control, documentation practices, and automation-related activities.

## Technologies and Tools

- C++
- Python
- Flask
- Docker
- Docker Compose
- Git and GitHub

## Repository Structure

- `proyecto/`: Main project materials and implementation work.
- `semanas/`: Weekly coursework, laboratory exercises, documentation, and supporting resources.
